# 🌱 Smart Plant Health Predictor

An AI/ML-based project that analyzes plant and environmental conditions such as **soil moisture, temperature, humidity, and sunlight** to predict the health condition of a plant.

This project is designed as a beginner-friendly hands-on project using **Python, Pandas, Machine Learning, and Google Colab**.

---

## 📌 Project Overview

Plant health is strongly influenced by environmental conditions. Monitoring parameters such as soil moisture, temperature, humidity, and sunlight can help identify whether a plant is healthy or requires attention.

The **Smart Plant Health Predictor** uses environmental data to analyze plant conditions and predict the corresponding health status.

### Input Parameters

- 🌱 Soil Moisture
- 🌡️ Temperature
- 💧 Humidity
- ☀️ Sunlight

### Output

The system predicts the plant health condition, such as:

- **Healthy**
- **Needs Attention**

## 📊 Dataset

The dataset contains environmental parameters related to plant health.

### Features

| Feature | Description |
|---------|-------------|
| `soil_moisture` | Moisture level present in the soil |
| `temperature` | Environmental temperature |
| `humidity` | Relative humidity |
| `sunlight` | Amount/intensity of sunlight |
| `health` | Plant health condition / target variable |

The dataset is used to train and evaluate the machine learning model.
